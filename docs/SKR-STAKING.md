# SKR staking endpoint

`GET /v1/solana-mainnet/skr/stake?owner=` reads the owner's position in Solana Mobile's SKR staking program (specs 021 and 022). This is the endpoint's contract and how each field is computed.

`GET /v1/solana-mainnet/skr/stake?owner=` (`max-age=60`; 404 `not_found` on any other network, 400 on a bad owner): the owner's positions in Solana Mobile's SKR staking program (`SKRskrmtL83pcL4YqLWt6iPefDqwXQWHSw9S9vz94BZ`, `UserStake` accounts found at byte 41, 169 bytes; layouts from the on-chain Anchor IDL), `{ mint, decimals: 6, sharePrice, cooldownSeconds, apy | null, usdPrice | null, liquid, totalStaked, logo | null, payouts: { intervalSeconds, lastAt, nextAt } | null, historySince | null, positions: [{ address, staked, earned, guardian: { pool, name | null, commissionBps, active }, unstaking: { amount, withdrawableAt } | null, stakedSince | null, history: [{ at, earned }] }] }`, amounts as base-unit strings, times in epoch ms. `staked = shares × share_price / 10^9`, `earned = shares × (share_price − cost_basis) / 10^9` in integer arithmetic. The share price is recorded per UTC day (`skr_share_price:<UTC day>`, 400 days): by `recordSkrSharePriceJob` at 02:05 UTC, just after the payout, overwriting the day, and by a request when the day has no record yet. `history` is exact (spec 022): between consecutive price points (records, and the owner's `Staked` / `Unstaked` / `UnstakeCancelled` events read from its own transactions through the program's `emit_cpi` instructions, each transaction's events cached 400 days) the position held a known number of shares, so each row is `shares × Δprice / 10^9`, counted in the record that closes it; rows without growth are dropped, nothing before the earliest record counts, and `historySince` is that record's time. When the owner's transactions cannot be read the history is empty, never inexact (`[SKR_HISTORY]`). `payouts` comes from the SKR inflation program's state account (`FMNn5sorEBbEoGQGrh7y3xSbYGt116F12FpL2VTsohiw`: interval at byte 29, start at 37, payouts made at 158; matched against the 02:00 UTC mints every 48 h): `lastAt = (start + count × interval) × 1000`, `nextAt = lastAt + interval`. `apy` annualizes the widest span of records once it reaches 7 days. Guardian names come from a documented list (pools have no name on chain). `stakedSince` is the position's oldest indexed signature, null when the provider indexes none (Triton does not for some positions). `liquid` is the owner's SKR outside staking (its SKR token accounts, base units). `totalStaked` is everything staked in the program, `StakeConfig.total_shares × share_price / 10^9` (base units). `logo` is SKR's image from the token catalog (`token-catalog-service.logoOf`), so a wallet with all its SKR staked still shows it; null when the catalog cannot give one (`[CATALOG_LOGO]`). `usdPrice` (both stake endpoints) is the CoinGecko quote of SKR / wrapped SOL through `getTokenPrices`, null when it cannot be had — a missing price never fails the read (`[STAKING_PRICE]`). Read-only (spec 021).
