## Dagon configuration (`devnet.json`, remote, cached 5 min)

| Field                                                                       | Used for                                  | Accepted when                                                   |
| --------------------------------------------------------------------------- | ----------------------------------------- | --------------------------------------------------------------- |

| `programs.{encrypt,pcToken,pcSwap}`                                         | guard                                     | equal the pinned ids                                            |
| `encryptGrpcUrl`                                                            | executor base URL                         | `https:` and hostname `pre-alpha-dev-1.encrypt.ika-network.net` |

| `sides.{USDC,DOGE}.{splMint,pcMint,vault,vaultAta,decimals}`                | per-side accounts                         | valid base58; `decimals` integer                                |
| `pool.{address,sideA,sideB,vaultAccountA/B,vaultBalanceCtA/B,reserveCtA/B}` | swap accounts                             | valid base58; `sideA`/`sideB` two distinct keys of `sides`      |

## Build request (query string of `GET /powerups/dagon/build`)

| Field                                                                  | Actions                               | Validation (before any executor or upstream call, FR-007)                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------- | ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `publicKey`                                                            | all                                   | controller: present, valid address (`solana-powerups-controller.js:28-39`)                                                                                                                                                                                                                                                                     |
| `action`                                                               | all                                   | one of the eight actions                                                                                                                                                                                                                                                                                                                       |
| `freshSigners`                                                         | all                                   | a string (not repeated); `''` → `[]`; split on `,`, no empty entries; each a valid address; distinct; count = the entry's `freshSigners[action]`; distinct from `publicKey`, `viewer`, `to`, `owner`, `burnedCt`, `requestAcct` → else 400 `invalid_fresh_signers`. At build time, any of them existing on chain → 400 `invalid_fresh_signers` |
| `side`                                                                 | setup, wrap, reveal, send, unwrapBurn | a key of `devnet.json` `sides` (checked at build time, after the config loads) → else 400 `invalid_parameter`                                                                                                                                                                                                                                  |
| `sideIn`, `sideOut`                                                    | swap                                  | both known, different, and the pool's two sides                                                                                                                                                                                                                                                                                                |
| `amount`                                                               | wrap, send, unwrapBurn                | decimal integer string, 1 ≤ n < 2^64, parsed as BigInt                                                                                                                                                                                                                                                                                         |
| `amountIn`, `minAmountOut`                                             | swap                                  | same as `amount`                                                                                                                                                                                                                                                                                                                               |
| `owner`                                                                | setup (optional, default `publicKey`) | valid address                                                                                                                                                                                                                                                                                                                                  |
| `viewer`                                                               | reveal                                | valid address, ≠ `publicKey`                                                                                                                                                                                                                                                                                                                   |
| `to`                                                                   | send                                  | valid address, ≠ `publicKey`                                                                                                                                                                                                                                                                                                                   |
| `burnedCt`                                                             | unwrapDecrypt, unwrapComplete         | valid address                                                                                                                                                                                                                                                                                                                                  |
| `requestAcct`                                                          | unwrapComplete                        | valid address                                                                                                                                                                                                                                                                                                                                  |
| any key matching `/secret\|private\|seed\|mnemonic\|keypair\|signed/i` | —                                     | 400 `invalid_parameter` (FR-008)                                                                                                                                                                                                                                                                                                               |

Missing required field → 400 `missing_parameter`; anything else malformed → 400 `invalid_parameter`. Amounts are base units (2 decimals for the mock tokens). Unknown extra keys are ignored.

## Fresh signer

A public key the device generated for one transaction. The backend names it as a signer account (`isSigner: true`) in exactly one place per action and nothing else: it never generates, receives or logs a private key.

| Action        | The fresh key is                        |
| ------------- | --------------------------------------- |
| setup         | the new pc-account's balance ciphertext |
| wrap          | the amount ciphertext                   |
| reveal        | the balance copy (`viewCt`)             |
| swap          | the swap receipt (`receiptCt`)          |
| unwrapBurn    | `burnedCt` (also seeds the receipt PDA) |
| unwrapDecrypt | the decryption request account          |

## Executor input

A ciphertext account the executor creates from a plaintext amount at the adapter's request (`research.md` R3), authorized to pc-token (send, unwrapBurn) or pc-swap (swap: amountIn, minAmountOut, 0). Usable once its status byte `[99]` is 1. Never reused; an input created for a build the user never sends stays on devnet unused.

## Chain state the adapter reads (one `getMultipleAccountsInfo` per action where possible)

| Action         | Reads                                                                                          | Refusals                                                                                                                                                                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| setup          | pc-account PDA(side, owner); deposit PDA(payer); Encrypt config                                | pc-account exists → 409 `already_initialized`                                                                                                                                                                                                    |
| wrap           | pc-account(caller)                                                                             | missing → 409 `setup_required`                                                                                                                                                                                                                   |
| reveal         | pc-account(caller)                                                                             | missing → 409 `setup_required`                                                                                                                                                                                                                   |
| send           | pc-account(caller), pc-account(to), sender balance ciphertext                                  | caller missing → 409 `setup_required`; `to` missing → 409 `recipient_setup_required`; sender balance pending or never committed → 409 `balance_settling` (FR-029)                                                                                |
| swap           | pool, pc-account(caller, in), pc-account(caller, out), both balance ciphertexts, both reserves | pool missing → 503 `pool_unavailable`; either pc-account missing → 409 `setup_required`; input balance never committed (all-zero digest) or pending → 409 `balance_settling`; reserves still pending when the wait ends → 503 `pool_unavailable` |
| unwrapBurn     | pc-account(caller), vault                                                                      | missing → 409 `setup_required`                                                                                                                                                                                                                   |
| unwrapDecrypt  | receipt PDA(burnedCt), burnedCt                                                                | receipt missing, not 203 bytes, or owner ≠ caller → 409 `receipt_not_found`; `decrypt_requested` ≠ 0 → 409 `already_requested`; burnedCt pending → 409 `balance_settling` (FR-030)                                                               |
| unwrapComplete | receipt PDA(burnedCt)                                                                          | missing / not the caller's → 409 `receipt_not_found`; `requestAcct` ≠ receipt `request` → 400 `invalid_parameter`; side from the receipt's `pc_mint`                                                                                             |

## Build result (`display`, scalars only, `solana-powerup-build-resource.js:33-36`)

`{ action, side?, sideIn?, sideOut?, amount?, amountIn?, minAmountOut?, recipient?, owner?, decimals, outcomeKnownAfterReveal: true }`. Amounts are strings (u64). Never an outcome, a quote, an expected output or a success word (FR-024).
